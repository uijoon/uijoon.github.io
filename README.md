# Personal Academic Website

This website is adapted from [Jon Barron's academic website](https://jonbarron.info/) and its [public source repository](https://github.com/jonbarron/jonbarron.github.io).

## Main files

- `index.html`: personal information, links, research statement, publications, and projects
- `stylesheet.css`: typography, colors, spacing, and shared visual styles

Search for `TODO` in `index.html` to find every field that must be replaced.

## Optional assets

Create these paths only when they are needed:

- `assets/profile.jpg`: profile photograph
- `assets/cv.pdf`: curriculum vitae
- `assets/publications/`: publication thumbnails, videos, or supplementary files

After adding local assets, update their corresponding paths in `index.html`.
